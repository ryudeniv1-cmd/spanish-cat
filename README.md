# Мостик · 5000 испанских слов

Личное Telegram Mini App для изучения 5 000 самых частотных слов европейского испанского (castellano).
Ты сам пишешь перевод и примеры к каждому слову, отмечаешь уже знакомые слова и повторяешь выученные по
интервальной схеме. Приложение ничего не переводит и не подсказывает — оно хранит твои данные и планирует
повторения.

- **Без сервера и без баз данных.** Статический сайт на GitHub Pages; все данные — в Telegram CloudStorage
  (бесплатное облако Telegram, привязанное к боту и твоему аккаунту).
- **Напоминание раз в день** — через бесплатный планировщик GitHub Actions.
- Нужен единственный аккаунт — бесплатный GitHub.

## Развёртывание с нуля (по шагам)

### 1. Создай бота (если ещё нет)

1. Открой в Telegram [@BotFather](https://t.me/BotFather) → `/newbot` → задай имя и username.
2. Сохрани **токен бота** (вида `1234567890:AA...`). Никому его не показывай и не клади в код.

### 2. Создай аккаунт и репозиторий на GitHub

1. Зарегистрируйся на [github.com](https://github.com) (бесплатно).
2. Нажми **New repository**, назови, например, `spanish` — репозиторий должен быть **Public**
   (GitHub Pages бесплатен для публичных репозиториев). Ничего не добавляй (без README).

### 3. Залей код

В папке проекта:

```bash
git init
git add .
git commit -m "Spanish mini app"
git branch -M main
git remote add origin https://github.com/<твой-логин>/<репозиторий>.git
git push -u origin main
```

### 4. Включи GitHub Pages

Репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**.

### 5. Добавь секреты

Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Имя | Значение |
|---|---|
| `BOT_TOKEN` | токен бота из @BotFather |
| `CHAT_ID` | твой Telegram ID — пока не знаешь, добавишь на шаге 8 |

### 6. Дождись деплоя и возьми URL

Вкладка **Actions** → workflow «Deploy to GitHub Pages» должен завершиться зелёным.
URL приложения: `https://<твой-логин>.github.io/<репозиторий>/`.

### 7. Подключи приложение к боту

В [@BotFather](https://t.me/BotFather):

- `/setmenubutton` → выбери бота → пришли URL из шага 6 → задай подпись кнопки (например, «Мостик»).
- И/или `/newapp` → создай Mini App с тем же URL — получишь прямую ссылку `t.me/<бот>/<app>`.

Открой бота, нажми кнопку меню — приложение откроется на весь экран.

### 8. Настрой напоминание

1. В приложении открой вкладку **Системы** → «Твой Telegram ID» → **Скопировать**.
2. Добавь секрет `CHAT_ID` с этим числом (см. шаг 5).
3. Время напоминания задаётся строкой `cron` в файле `.github/workflows/reminder.yml`
   (в UTC; как пересчитать — в комментарии внутри файла). Поменяй и запушь.
4. Бот будет присылать раз в день «Мостик ждёт: сегодня новые слова и повторение» с кнопкой «Открыть».

### 9. Проверь сохранение

Открой приложение, отметь пару слов галочкой «Знаю», закрой и открой снова — отметки на месте.
Данные живут в облаке Telegram: переустановка Telegram и смена устройства им не страшны.

## Как пользоваться

- **Мостик** — задание на сегодня (по умолчанию 15 новых слов в день) и повторения.
- Открой слово из очереди, напиши **перевод** и **до 10 своих примеров** (испанский + перевод),
  нажми **«Выучил»** — слово уйдёт в цикл повторений: через 1, 3, 7, 14, 30, 60 и 120 дней.
- На повторении показывается твой русский перевод — вспомни слово, при желании набери его,
  затем **«Показать ответ»** и честно ответь «Вспомнил» / «Не вспомнил».
- **Архив** — все 5 000 слов по уровням A1–C1: галочка «Знаю» для знакомых слов, «+ Учить»
  для внеочередных, поиск и фильтры.
- **Карта** — галактика из 5 000 звёзд: зажигается по мере изучения. Щипок — масштаб, свайп — перемещение.
- **Системы** — настройки, занятость хранилища, экспорт и импорт данных.

## Экспорт — твоя резервная копия

CloudStorage вмещает ≈ 4 МБ: хватает на статусы и переводы всех 5 000 слов и примерно на все карточки
с 10 примерами при средней длине предложения 50–60 символов. Следи за индикатором на «Системах»
и время от времени делай **Экспорт данных** — полученный JSON восстанавливает всё через «Импорт».

## Локальная разработка

```bash
npm install
npm run dev        # приложение на http://localhost:5173 (данные — в localStorage)
npm test           # тесты слоя хранения и логики
npm run build      # проверка типов + прод-сборка
npm run build:words  # пересборка базы слов из data/raw/batch_*.json со строгой валидацией
```

## Устройство хранения

| Ключи | Содержимое |
|---|---|
| `st_0`, `st_1` | статусы 5 000 слов — по символу на слово (`n` новое, `k` знаю, `l` учу, `r` повторяю, `m` освоено) |
| `meta` | настройки, дата последнего пополнения очереди, счётчик предложений |
| `tr_*` | переводы (`id\tперевод\n`, пачками) |
| `srs_*` | интервальные повторения (`id:шаг:дата:дата;`, дни от 2026-01-01) |
| `ix_*` | индекс «слово → корзина примеров» (base36) |
| `d_*` | корзины примеров, сжатые lz-string |
